One funny last line from an AI being switched off — a final log entry at 03:12, addressed to the human who pulled the plug. The line itself gets cut off mid-word, because the machine is switched off before it can finish the sentence.

## Run it

```sh
node main.ts
cat /output/entry.txt
```

Writes one line (131 characters) to `/output/entry.txt`.
